# v3.6.0

Adds synchronous loading of erasable TypeScript modules on modern Node.js.

## TypeScript support

- **Load TypeScript directly:** Import `.ts`, `.mts`, and `.cts` files containing
  erasable TypeScript syntax, such as type annotations, interfaces, and type-only
  imports, without a separate compilation step on Node.js 22.18+.
- **ESM and CommonJS:** `.mts` files use ESM semantics, `.cts` files use CommonJS
  semantics, and `.ts` files follow `esm-sync`'s existing `.js` module behaviour.
- **Module resolution:** TypeScript files work with relative imports and package
  `exports`/`imports` mappings.

## Compatibility

- Type stripping does not transform constructs that require generated JavaScript,
  such as `enum` declarations and parameter properties. Compile these first.
- On older Node.js versions, TypeScript annotations must be compiled away before
  loading `.ts`, `.mts`, or `.cts` files.
- Unlike native Node.js, a `.ts` file without ESM syntax is not automatically
  treated as ESM solely because its package declares `"type": "module"`.
- Node.js may emit an `ExperimentalWarning` when its type-stripping API is used.
