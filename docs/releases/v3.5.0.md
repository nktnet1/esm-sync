# v3.5.0

Faster ESM imports and better compatibility with modern Node.js packages.

- **Performance:** Faster loading of large ESM graphs, re-exports, and cached modules.
- **Resolution:** Improved package `exports`/`imports` conditions, `import.meta`, and dynamic imports.
- **Import support:** Added source-phase and immutable bytes imports on supported runtimes.
- **Interop:** Fixed live bindings, CommonJS default exports, and recovery from failed imports.
- **Tooling:** Better compatibility with Jest and coverage tools, Node REPLs, Electron, and VS Code.
- **Reliability:** Fixed `.esmrc` startup failures and a parser hang on invalid Unicode.
